Rankus 서비스 기능 명세서 (상세)

📌 1. 회원 관리 및 인증

회원가입 및 로그인
	•	회원가입 필수 필드
	•	이름, 학번, 학년, 이메일, 비밀번호, 학생/교수 여부
	•	이메일 중복 검사 및 인증 메일 발송
	•	교수 가입 시, 관리자 승인 후 랩장 연결 기능 구현
	•	비밀번호 조건 (최소 8자리, 특수문자, 숫자 혼합 필수)
	•	로그인 시 JWT 토큰 생성 및 관리
	•	비밀번호 암호화 및 보안 처리 (BCrypt 권장)

추가 검토 사항:
	•	비밀번호 분실 시 재설정 방법 (이메일 기반)
	•	개인정보 처리 방침 고지 화면 제공

⸻

📌 2. 랩실 홍보 및 가입신청

🔖 2.1 랩실 목록 페이지
	•	랩실 미리보기 표시 항목
	•	랩실 이름, 대표 이미지, 랭킹 순위, 연구 주제 요약
	•	정렬 기준
	•	기본: 랭킹 높은 순
	•	추가 필터: 연구 주제, 최신순 등
	•	무한 스크롤 성능 최적화 (페이징 처리 필수)
	•	프론트엔드: React Intersection Observer 활용

🔖 2.2 랩실 상세 페이지
	•	본문 WYSIWYG 에디터(Quill.js 권장) 사용
	•	이미지 다중 업로드 및 CDN 활용 (AWS S3 권장)
	•	하단 가입 신청 버튼 배치 (미로그인 시 로그인 유도)

🔖 2.3 가입 신청 페이지
	•	신청 기간 명시 (시작/마감일자 자동 처리)
	•	개인정보 사용 고지 필수 체크 항목
	•	면접 시간 신청 및 충돌 방지 로직 구현 (선택 가능 시간대 표시)

추가 검토 사항:
	•	가입 신청 취소 기능 필요 여부
	•	신청 상태 확인 페이지 구현 필요 여부

⸻

📌 3. 랩실 운영 및 관리 기능

🔖 3.1 메인 페이지 및 대시보드
	•	공지, 캘린더, 투표 최신 게시물 미리보기
	•	QR 출석 체크 바로가기 및 관리 도구 제공
	•	관리자 페이지 별도 접근 관리

🔖 3.2 QR 출석 체크 기능
	•	출석 시작/종료 권한 (임원/랩장 제한)
	•	QR 코드 유효시간 명시 (5분)
	•	QR 스캔 시 정확한 시간 기록 및 중복 체크 로직
	•	출석 내역 상세 조회 및 CSV 내보내기 기능 제공

🔖 3.3 캘린더 기능
	•	권한별 일정 등록 가능 여부 명확화 (임원, 랩장, 교수)
	•	캘린더 UI: FullCalendar.js 사용 추천
	•	일정 등록 시 알림 기능 제공 (이메일 또는 푸시 알림)

🔖 3.4 인원 관리 기능
	•	랩장 및 임원만 인원 추가/삭제 및 정보 수정 가능
	•	인원 권한 부여 명확화 (임원 권한 설정)
	•	출석 현황 조회 및 수정 기능 상세화
	•	면접 신청자 관리 세부 기능
	•	면접자 신청 목록 및 메모 작성
	•	별표 즐겨찾기 기능
	•	구글 캘린더 형태의 시간대 관리 및 충돌 방지 로직

🔖 3.5 공지 관리 기능
	•	WYSIWYG 에디터 (Quill.js 권장) 사용
	•	공지 중요도 설정 및 상단 고정 기능 구현
	•	작성 즉시 알림 전송 옵션 제공

🔖 3.6 홍보 페이지 관리 기능
	•	권한 관리 (랩장/임원)
	•	사진 업로드 시 자동 압축 및 CDN 연결
	•	수정 이력 관리 기능 (작성자, 수정일자 기록)

⸻

📌 4. 랩실 랭킹 기능 (구체화)

🔖 4.1 점수 산정 및 신청 프로세스
	•	점수 신청 항목 명확화 및 점수 기준표 제작
	•	교육 프로그램 수료 (10점)
	•	교내/외 대회 수상 (대상 30점, 금상 20점, 은상 10점 등)
	•	전공 A+ 학점 인증 (5점/과목당)
	•	학과 성적 장학금 수령 (15점)
	•	관련 자격증 취득 (국가자격증 20점, 민간자격증 10점 등)
	•	점수 산정 로직:
	•	랩원이 증빙서류 업로드 → 랩장(임원)이 승인 → 점수 자동 부여 및 누적 관리

🔖 4.2 랭킹 집계
	•	점수 누적 방식으로 일일 집계 및 랭킹 실시간 갱신
	•	점수 신청 및 승인 프로세스 관리 페이지 별도 구현
	•	랭킹 변동 그래프 제공 (사용자 동기 유발)

추가 검토 사항:
	•	점수 조정 및 삭제 기능 (잘못된 승인 대비)
	•	관리자 전용 랭킹 점수 이력 조회 페이지 필요성 검토

⸻

📌 5. 관리자 페이지
	•	회원가입 승인/거절 및 권한 관리
	•	랩실 전체 통계 (가입률, 출석률, 랭킹 현황 대시보드)
	•	시스템 로그 관리 (회원 활동 내역 추적 가능)

⸻

📌 6. 기술 및 성능 고려사항

백엔드
	•	Spring Boot, JPA 사용
	•	REST API 디자인 일관성 유지 (Swagger 문서 필수)
	•	AWS EC2 배포 및 Docker-compose 환경 구축 필수
	•	Redis 캐싱 도입 검토

프론트엔드
	•	React 기반 컴포넌트 설계
	•	상태관리 명확화 (Zustand 또는 Redux 사용)
	•	모바일 호환성 고려한 반응형 웹 구축 필수

DB
	•	MySQL 사용 (RDS 권장)
	•	성능 최적화 위한 인덱스 설정

보안
	•	JWT 기반의 토큰 관리 및 Spring Security 구현
	•	민감 데이터 암호화 처리 (AES256 권장)

⸻

📌 7. 테스트 및 예외 처리 명확화
	•	도메인별 Enum 활용한 예외 처리 표준화
	•	Mockito 기반 서비스 로직 단위 테스트 작성
	•	통합 테스트 및 E2E 테스트 계획 수립 필요

📌 ✨ 추가 요구사항 정리가 필요한 부분 (다음 단계에서 필요)
	1.	점수 부여 기준의 세부화
	•	증빙 문서 형식 지정 (pdf, jpg 등)
	•	점수의 유효기간 설정 여부 검토 (한 학기, 1년 등)
	2.	면접 신청 및 관리의 사용자 Flow 추가 구체화
	•	면접자 입장 및 신청 변경 로직 추가 고려
	•	면접 평가 항목 및 관리 방법 명확화
	3.	알림 시스템의 세부 설계
	•	이메일 및 푸시 알림 서비스 선정(Firebase 등)
	4.	관리자 시스템의 기능 확장성
	•	랩실 평가 항목 관리 (추후 변경 가능성 고려)
	5.	데이터 관리 정책
	•	데이터 백업 및 복구 방안 구체화
	•	개인정보 처리 규정 명확히 수립 및 문서화
