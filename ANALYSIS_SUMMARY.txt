MAJOR FINDINGS:
================================================================================

1. HEXAGONAL ARCHITECTURE TRANSFORMATION (June 8, 2025)
   - Deleted 4,495 lines, added 1,627 lines (60% reduction)
   - Fundamental shift from framework-coupled to domain-focused
   - Enabled independent testing of domain logic
   - Impact: Better testability, cleaner separation of concerns

2. PERMISSION SYSTEM EVOLUTION (July-October 2025)
   - Phase 1: Simple scattered role checks (naive)
   - Phase 2: @PreAuthorize annotations (better)
   - Phase 3: Domain-aware permission handlers (correct)
   - 8 specialized handlers consolidating logic
   - User domain model encodes permission rules

3. JWT REFRESH TOKEN JOURNEY (August 2025)
   - 3 iterations to get it right
   - Attempt 1: Too short for development
   - Attempt 2: Too long, no rotation (failed approach)
   - Attempt 3: Proper rotation with refresh tokens
   - Added: Token blacklisting for logout
   - Lesson: Stateless JWT requires stateful refresh mechanism

4. CONCURRENCY CONTROL (July 22, 2025)
   - Problem: Race condition on interview slot booking
   - Multiple students could book same slot simultaneously
   - Solution: Pessimistic row-level locking (SELECT FOR UPDATE)
   - Added retry logic with exponential backoff
   - Verified: Only 1 of 4 concurrent bookings succeeds

5. QR TOKEN SECURITY (October 2-3, 2025)
   - Evolution from plain text to cryptographically secure
   - Legacy format: Readable concatenation (vulnerable)
   - Secure format: AES-256-GCM encryption
   - Properties: Confidentiality + Integrity + Authenticity
   - Dual-format support: SECURE with LEGACY fallback

6. TEST INFRASTRUCTURE
   - 90+ integration test cases
   - Test factory pattern for consistency
   - 95% domain coverage, 90% service coverage
   - JaCoCo integration for tracking

================================================================================
LESSONS LEARNED:
================================================================================

1. Hexagonal architecture enables true testing
   - Domain can be tested without Spring context
   - Services become use-case focused
   - Adapters become interchangeable

2. Permission system is cross-cutting concern
   - Scattered checks lead to inconsistency
   - Unified handlers enable auditing
   - Domain objects should understand their own permissions

3. Token rotation beats long expiry
   - Stateless JWT + stateful refresh tokens = best of both
   - Short-lived tokens (1 hour) prevent compromise
   - Refresh tokens allow graceful expiry
   - Blacklist enables immediate logout

4. Concurrency requires careful design
   - Optimistic locking insufficient for scarce resources
   - Pessimistic locking trades latency for correctness
   - Retry with backoff prevents thundering herd
   - Always re-check conditions after acquiring locks

5. Encryption is essential, not optional
   - Plain text QR codes expose internal IDs
   - AES-256-GCM provides confidentiality + integrity
   - Random IVs prevent patterns
   - Authentication tags detect tampering

6. Testing infrastructure determines maintainability
   - Factory pattern enables consistent test data
   - 90+ tests require automation, not copy-paste
   - Comprehensive coverage catches regressions
